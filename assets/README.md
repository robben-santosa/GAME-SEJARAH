# Assets — Jelajah Perang Padri

Folder ini disiapkan untuk aset opsional. Game berjalan penuh TANPA aset,
karena semua visual dibangun dengan CSS illustration + SVG + emoji.

Struktur yang disarankan:

- assets/characters/   -> gambar karakter (png/svg)
- assets/backgrounds/  -> gambar latar lokasi
- assets/icons/        -> ikon (fakta, peta, skor)
- assets/audio/        -> musik/sfx opsional (.mp3 / .ogg)

Jika file audio tidak ada, game tetap berjalan normal (sistem audio
menggunakan Web Audio sintetis dan dapat dimatikan dengan tombol SOUND).
